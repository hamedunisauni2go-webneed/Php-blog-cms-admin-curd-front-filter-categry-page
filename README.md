# 📰 Core PHP Blog / Job Portal CMS

A simple and powerful **Blog + Job Portal Content Management System** built using **Core PHP & MySQL**.  
It includes an admin panel to manage blogs and a responsive frontend for users.

---

## 🚀 Features

### 🔐 Admin Panel
- Secure login/logout system
- Add / Edit / Delete blogs
- Upload blog images
- Rich text editor (CKEditor)
- Category management (Latest Jobs, Admit Card, Results)
- View all posts in dashboard
- Success / error alert system

---

### 🌐 Frontend Website
- Responsive blog listing page
- Category filter (dropdown)
- Single blog page (Read More)
- Clean UI for mobile and desktop
- Latest posts display
- Dynamic content from database
